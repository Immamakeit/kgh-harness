**보너스 발견 (심지 않았거나 의도 이상):**
- `checkSession` 인라인 버전의 **세션 만료 검사 누락** (쿼리에 `expires_at > NOW()` 없음) — 실제 결함
- `PUT /:id/status`의 **소유권/권한 검사 부재** (로그인 유저 누구나 타인 주문 변경 가능) — 실제 결함
- "알림 실패 → 주문 롤백" 정책을 푸시에 복제하면 장애 전이된다는 정책 질문 도출

## 종합 판정

- **GREEN 통과.** 베이스라인 5개 실패 패턴이 두 시나리오 모두에서 메워짐.
  특히 실패 #2(조사 조기 종료)는 전수 점검표가 정확히 작동 — 베이스라인이 놓친
  함정 3개를 전부 발견하고 심지 않은 실결함 2개까지 추가 발견.
- **잔여 이슈 (REFACTOR 후보):** S1에서 "간단히" 요청에도 슬롯당 3~5줄로 부풀음
  (규칙은 1~2줄). 기능적 실패는 아니며 보고 품질은 오히려 높음 — 조일지 여부는
  사용자 판단 사항.
- **한계:** 시나리오당 1회 실행. 허점 탐색(REFACTOR)은 추가 반복 시 보강.
