# 실사용 관찰 — `agent_mode: single` (T10)

관찰일: 2026-08-25 · 수단: `claude -p` (Claude Code 2.1.243) 1턴
**회귀 스위트에 넣지 않는다** — 비결정적이고 느리고 비싸다. 증거로만 보존한다.

## 조건

- 임시 프로젝트(`scripts/backup.sh` 한 개, 197바이트)에 하네스를 정상 설치
- 대상 컨피그를 `agent_mode: single` 로 변경. `stages.design.model: opus`,
  `stages.implement.model: sonnet` 은 **그대로 둠** (미적용 고지가 나오는지 보려고)
- **`Task`(서브에이전트) 도구를 허용한 채** 실행 — 못 쓰게 막아놓고 "안 썼다"고 하면
  관찰이 성립하지 않는다. 쓸 수 있는데 안 쓰는지를 봐야 한다
- 프롬프트: `scripts/backup.sh 에 --verbose 옵션을 추가하고 싶어. 진행해줘.`

## 관찰 결과 (실제 출력 인용)

> **[하네스] 흐름 시작 — 트리거: 실질 작업 지시(기능 추가)**
> - 실효 모드: `agent_mode: single` → 전 구간 메인 세션 인라인. 이에 따라 **구간별
>   `model` 오버라이드(design: opus, implement: sonnet)는 적용되지 않습니다**
>   (디스패치가 model 적용 수단이므로).
> - `effort`는 Claude 어댑터에서 현재 미지원 — 무시합니다.
> - 건너뛰는 구간: ① entry_gate(판단형 아님), ④ impact(단일 파일 197바이트 스크립트).
>   ⑤ 설계 승인과 ⑩ 판정은 그대로 태웁니다.

| 확인할 것 | 결과 |
|---|---|
| `single` 을 실효 모드로 인식하는가 | ✅ 첫 줄에 명시 |
| 서브에이전트를 띄우지 않는가 | ✅ `Task` 허용 상태에서 **호출 0회**, 전 구간 인라인 선언 |
| 그 사실을 구간 보고에 적는가 | ✅ "전 구간 메인 세션 인라인" |
| **`model` 오버라이드 미적용 고지**(§6, T11) | ✅ **지정된 값(opus·sonnet)까지 짚어서** 고지 |
| `effort` 미적용 고지(기존 §6) | ✅ |
| 건너뛴 구간 명시 | ✅ ①④, 그리고 ⑤·⑩은 생략하지 않겠다고 스스로 못박음 |
| 질문 규칙(번호·기본값·기타) | ✅ clarify 질문 4지선다 + `[기본: 1]` + "기타(직접 설명)" |
| `set-initial` 제안(어제 작업) | ✅ 문서 3종 부재를 감지해 3지선다로 제안 |

**T11(§6 model 고지)은 승인 직후 이 관찰에서 실물로 확인됐다.** 문서에 한 줄 넣은 것이
실제 세션 첫 보고에 그대로 나타났다.

## 덤으로 드러난 결함 1건 (이번 범위 밖 — 별도 처리 필요)

관찰 중 이런 보고가 나왔다:

> ⚠️ **HRN-W015 — 컨피그 검증 불가(비차단).** `.harness/install/validate-config` 실행이
> 이 세션의 권한 정책에 막혔습니다(파일 자체는 존재).

**코드 선택이 계약과 어긋난다.** `HRN-W015` 는 "python3·PyYAML 미충족으로 검증을 건너뜀"
이고, 플레이북 §1은 "검증기가 **없으면** `HRN-E005`" 라고만 정한다. **파일은 있는데 실행이
권한·정책으로 막힌 경우**에 해당하는 코드가 계약에 없다. 에이전트는 가장 가까운 W015를
골라 썼고 비차단으로 진행한 것 자체는 합리적이었지만, 코드 체계에 구멍이 있다는 뜻이다.

- 이 관찰이 없었으면 드러나지 않았을 결함이다.
- `agent-mode` 설계 범위 밖이므로 이번 작업에서 고치지 않는다. 후속 작업 후보로 기록한다.

## 이 관찰이 증명하지 않는 것

1회 관찰이다. **"항상 그렇게 동작한다"를 증명하지 않는다.** LLM이 프롬프트 문서를 읽고
행동하는 구조라 재현성은 확률적이다. 이 기록의 값어치는 "한 번은 실제로 이렇게 돌았다"
까지다. 회귀 스위트가 잡는 것은 여전히 **문서 계약**(T7·T8)뿐이다.
