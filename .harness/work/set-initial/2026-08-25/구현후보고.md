## 3. 검증 결과

- **린트:** `shellcheck -S warning` — `install/{setup,update,lib.sh,validate-config}`,
  훅, 테스트 스크립트 **경고 0**. `bash -n` 전 파일 통과.
- **코드리뷰: 수행함 (2회차까지).** 사용자가 세션 지시로 서브에이전트 디스패치를 허용해
  컨피그대로 `verify.dispatch: true` · `superpowers:requesting-code-review` 를 실행했다.
  (앞서 이 항목을 "미수행"으로 적었던 것은 그 지시 이전 상태다 — 지시 후 실제로 돌렸다.)
  - **1회차** — 차단급 0건, 권고 3건. 리뷰어가 경계 입력을 직접 찔러봄: `PRD.md` 자리가
    디렉토리 · 깨진/순환 심볼릭 링크 · `chmod 000` · 바이너리 · 39MB 공백 파일 ·
    구버전 컨피그. **전부 rc=0, 훅이 죽는 경로 없음.** 설계 비대상 위반 0건.
    권고: ① 스킬 문서 자기모순(질문 계약 vs 1단계 예시) ② `bootstrap.prompt` 서브스키마가
    검증되지 않는데 검증되는 것처럼 보임(실측: 오타값 통과) ③ 경계 케이스가 회귀로 미고정.
  - **T9** — 셋 다 반영. 검증기 로직은 고치지 않았다(설계 §3-2가 하위 키 미검증을 택함).
  - **2회차** — 3건 모두 **닫힘, 뮤테이션으로 실증.** 리뷰어가 `doc_state()` 를 일부러
    `[ -e ]` 로 망가뜨리자 신규 3케이스가 정확히 FAIL(143 PASS/3 FAIL) → 테스트가 장식이
    아니라 계약을 고정함을 증명. 원복 후 146 PASS/0 FAIL·`git status` 청결까지 확인.
    새 차단급 0건, 참고 3건(그중 2건은 이 보고 직전에 반영, 나머지 1건은 root 환경에서
    SKIP 이 PASS 로 집계된다는 통계 표기 문제 — 사유는 메시지로 공개됨).
- **요건 충족:**

  - GREEN 실행은 **전부 기본값 경로**만 밟았다. `직접 입력`·`건너뛰기`·`취소` 는

## 4. 직접 확인 시나리오

1. 빈 프로젝트에 설치한다.
   ```bash
   S=$(mktemp -d); git clone -q ~/dev/kgh-dev-harness "$S/h"; mkdir -p "$S/p"
   "$S/h/install/setup" "$S/p" </dev/null | tail -4
   ```
   - **기대 결과:** "다음 할 일"에 `PRD.md·CLAUDE.md·AGENTS.md가 없으면 그 세션에서
     초기 세팅을 제안합니다 (set-initial)` 줄이 보인다.

2. 훅이 문서 상태를 보고하는지 본다.
   ```bash
   CLAUDE_PROJECT_DIR="$S/p" bash "$S/p/.harness/adapters/claude/hooks/session-start.sh" \
     | grep -A2 '기반 문서 상태'
   ```
   - **기대 결과:** `PRD.md: 없음 · CLAUDE.md: 없음 · AGENTS.md: 없음`

3. **부정 케이스 ①** — 공백뿐인 파일은 "있음"이 아니다.
   ```bash
   printf '\n  \n' > "$S/p/CLAUDE.md"
   CLAUDE_PROJECT_DIR="$S/p" bash "$S/p/.harness/adapters/claude/hooks/session-start.sh" \
     | grep 'CLAUDE.md:'
   ```
   - **기대 결과:** `CLAUDE.md: 없음`

4. 실제 세션에서 돌려본다 — `$S/p` 에서 Claude Code를 열고 `초기 세팅 해줘` 라고 한다.
   - **기대 결과:** 기존 문서 목록 → 처리 방식 6지선다 → 1단계 3문항. 모든 질문에
     `직접 입력`·`건너뛰기`·`[기본: N]` 이 붙어 있다.

5. **부정 케이스 ②** — 이미 문서가 있는 프로젝트에서 불러도 조용히 덮지 않는다.
   ```bash
   printf '# 규칙\n- 기존 내용\n' > "$S/p/CLAUDE.md"
   ```
   세션에서 다시 `초기 세팅 해줘`.
   - **기대 결과:** 목록에 `CLAUDE.md 2줄` 이 뜨고, git 상태를 확인했거나
     `CLAUDE.md.bak` 을 만들었다는 보고가 먼저 나온다. 백업 없이 덮어쓰지 않는다.

6. **부정 케이스 ③** — 끄면 안 묻는다. `harness.config.yaml` 에 `bootstrap: {prompt: off}`
   를 두고 세션을 연다.
   - **기대 결과:** 문서가 없어도 하네스가 먼저 제안하지 않는다. 직접 호출하면 그때는 돈다.

7. 전체 회귀.
   ```bash
   cd ~/dev/kgh-dev-harness && bash tests/install/run-tests.sh | tail -2
   ```
   - **기대 결과:** `PASS: 146  FAIL: 0`
