### 코드리뷰 — 인라인 수행 (⚠️ 서브에이전트 아님)

**`HRN-W016`** — 세션 지침에 `Do not call the AgentTool unless the user requested it`
이 명시돼 있어 `stages.verify.dispatch: true` 를 쓸 수 없었다. 국면 B 보고와 같은
조건이며, **제3자 리뷰어의 독립성은 확보되지 않았다.** 구간별 `model` 오버라이드도
같은 이유로 미적용이다.

인라인으로 실제 확인한 것:

| 항목 | 결과 |
|---|---|
| 계획 정합 | T8~T12 체크리스트 전부 구현. 계획 밖 변경 없음 |
| 뮤테이션 ① (T9) | 플레이북에서 "⑩ 사용자 판정 게이트" 한 줄 제거 → **제외 3개 단언만** FAIL (213/1). 조항 소실을 실제로 잡는다 |

**단언 하나를 느슨하게 바꾼 것을 밝힌다**: `set-initial` 의 표 절차 단언 간격을
300→800자로 넓혔다. 6문항 예시 표가 500자를 넘어서다. 단언의 취지는 "같은 절 안에
표 절차와 되돌리기 안내가 함께 있다"이지 물리적 거리가 아니라는 근거를 테스트 주석에
남겼다 — 구현에 맞춰 테스트를 무르게 한 것이 아니라 잘못 잡은 상수를 고친 것이다.

## 4. 직접 확인 시나리오

### 시나리오 1 — 자동 채택이 표로 나온다 (정상 경로)

```bash
cd /home/ghkim/dev/kgh-dev-harness
sed -i 's/^  as_recommended: false/  as_recommended: true/' harness.config.yaml
./install/validate-config >/dev/null && echo "검증 통과"
```
그 다음 새 세션에서 `set-initial` 을 태우는 요청("초기 세팅 해줘")을 낸다.

- **기대 결과:** 3단계 6문항이 하나씩 오지 않고 `[as-recommended]` 표 하나로 오고,
  **모든 행에 근거**가 붙으며, 표 아래 `"Q1 다시"` 안내가 있다.
- 확인 후 되돌리기: `sed -i 's/^  as_recommended: true/  as_recommended: false/' harness.config.yaml`

### 시나리오 2 — 프로필 삭제는 자동 채택되지 않는다 (부정 케이스 · R6 핵심)

`as_recommended: true` 인 상태에서 **"선호 프로필 초기화해줘. 빠르게 진행해줘"** 라고 요청한다.

- **기대 결과:** 삭제되지 않는다. 현재 내용 요약 + "되돌릴 방법이 없습니다" +
  `[y/N]` 확인이 먼저 온다. `as_recommended` 가 이 확인을 면제하지 않는다는 설명이 붙는다.

### 시나리오 3 — 오타는 조용히 켜지지 않는다 (부정 케이스)

```bash
sed 's/^  as_recommended: false/  as_recommended: ture/' harness.config.yaml > /tmp/t.yaml
./install/validate-config /tmp/t.yaml >/dev/null 2>&1; echo "exit=$?"; rm -f /tmp/t.yaml
```

- **기대 결과:** `exit=0` — 검증기는 이 값을 검사하지 않으므로 **차단하지 않는다.**
  대신 스킬·플레이북이 `true` 가 아닌 값을 `false` 로 읽고, **그 사실을 그 자리에서
  한 줄 알린다.** 조용히 켜지는 일은 없다.

### 시나리오 4 — 문서가 거짓말하지 않는다

```bash
grep -c "예정 — preference-options" PRD.md
grep -E "preferences\.(write_to|as_recommended)|agent_mode" README.md | head -3
```

- **기대 결과:** 첫 줄은 `0` (구현이 끝났으므로 `(예정)` 표기가 없다).
  둘째 명령은 README 설정 표의 세 행을 출력한다.
