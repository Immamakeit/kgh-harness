### 3-1. 린트

### 3-2. 코드리뷰 (서브에이전트 2회)

### 3-4. 알려진 잔여 (숨김 없이)

1. **`join_lines`의 개행 없는 마지막 줄 유실 (Low, 잠재)** — 메인 세션 재현:
   `printf 'a\nb\nc' | join_lines '·'` → `a·b` (**`c` 유실**). `while read` 고전 함정.
   **현재는 도달 불가** — 두 호출부 모두 `sort -u`를 거치고 `sort`는 항상 개행으로 끝난다
   (`printf 'z\ny\nx' | sort -u | xxd` → `780a 790a 7a0a`로 확인). 새 호출부가 생기면
   터진다. 수정은 `while IFS= read -r line || [ -n "$line" ]` 한 줄.
2. **grep 완전 부재 시 L1b가 죽은 코드 (Low, 기존 특성)** — `read_active_harness`도 grep에
   의존해 그보다 앞서 빈 값으로 새고, L1b는 "claude 아님 → 건너뜀"으로 빠진다.
   이번 변경이 만든 결함이 아니라 L1의 기존 성질. `detect_superpowers` 자체는 단위
   실험에서 `unknown` 정상 반환.
3. **`install/update`에는 동일 점검 없음** — 계획서 비대상. setup 1회 + 런타임 보고로 충분하다고 판단.
4. **shellcheck 미실행** (3-1).
5. **플레이북 §1-4 런타임 처리는 실동작 미검증** — 지침 문서라 실행 검증 대상이 없다.
   실제로 superpowers 없는 세션에서 흐름을 돌려야 드러난다.
