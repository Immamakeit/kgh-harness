## 3. 작업 방법 (예시 포함)

### T3 무장 판정 — 순수 bash 빠른 길

```bash
# 설계 문서는 있고 .approved 는 없는 디렉터리가 하나라도 있으면 무장.
for d in "$WORKROOT"/*/*/; do
  [ -f "${d}${DESIGN_NAME}" ] || continue
  [ -f "${d}.approved" ] && continue
  PENDING="$d"; break
done
[ -z "$PENDING" ] && exit 0      # 미무장 — JSON 파싱조차 하지 않는다
```

### T3 차단 메시지 (stderr, exit 2 — 모델에게 전달된다)

```
❌ HRN-E016 — ⑤ 설계 승인 전에는 구현할 수 없습니다 (승인 대기: <작업명>)
   차단된 조작: Edit /path/to/src.js
   조치: (a) 사용자 승인을 받은 뒤 .harness/install/approve <작업명> 실행
         (b) 게이트를 끄려면 harness.config.yaml 의 gate.enforce 를 off 로
```

### T8 심링크 — 상대 경로로 걸어 레포 이동에 견딘다

```bash
ln -s "../../.harness/skills/${name}" "${TARGET}/.claude/skills/${name}"
```
